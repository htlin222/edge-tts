接力棒掉在哪一棒，決定你補什麼。

以下綜論以 114 年血液專科考題為切入點，沿著 B12 吸收路徑的四棒接力，逐一解剖每個交接點失敗時所對應的截然不同臨床實體與治療邏輯。

維生素 B12 吸收的四棒接力：接力棒掉在哪一棒，決定你補什麼、怎麼補。

主軸一：四棒接力——每一棒的功能定位不可互換。

B12（cobalamin）從食物蛋白質到進入細胞，需要歷經一段精密的多蛋白接力，每一棒的角色都無法被其他棒次替代 。

第一棒｜唾液 haptocorrin（transcobalamin I，R-binder）——保護者。

B12 在食物中與蛋白質緊密結合。胃酸（低 pH）與胃蛋白酶（pepsin）的任務是把 B12「從食物蛋白質上切下來」，使其成為游離形式——這是吸收的前提條件，與下一步的接棒者無關 。游離的 B12 在胃內環境中若無保護，將被強酸破壞。此時，由唾液腺分泌的 haptocorrin 搶先與 B12 結合，在強酸環境中扮演「護鏢」角色，讓 B12 安全通過胃，抵達小腸 。
一個關鍵的認知校正：haptocorrin 又名 transcobalamin I。許多教科書把「在胃中與 B12 結合的蛋白質」簡化為 intrinsic factor（IF），但這是不精確的——在胃中率先出手的是 haptocorrin，而非 IF。

第二棒｜intrinsic factor（IF）——通行證。

IF 由胃壁細胞（parietal cells）分泌，但它與 B12 的真正結合發生在十二指腸，而非胃。其關鍵機制如下 ：

食糜進入十二指腸後，胰臟蛋白酶（pancreatic proteases）將 haptocorrin 分解
同時，鹼性胰液使腸腔 pH 上升
雙重條件成熟後，B12 才從 haptocorrin 手中交棒給 IF。

IF 是唯一能讓 B12 通過迴腸末端「海關」的通行證。沒有 IF，B12 無法被受體識別，絕大多數將隨糞便排出。

第三棒｜迴腸末端的 cubam 受體——收貨員。

Cubam 受體由兩個次單元組成：cubilin（負責識別並結合 IF-B12 複合體）與 amnionless（負責將 cubilin 錨定於細胞膜並介導訊號傳遞）。此受體位於迴腸末端（terminal ileum）的腸黏膜細胞表面。IF-B12 複合體與 cubam 結合後，經由鈣依賴性的胞吞（endocytosis）進入細胞，IF 在溶酶體中被降解，游離的 B12 釋出進入門脈循環 。

第四棒｜transcobalamin II（TC-II）——宅配員。

吸收入血後，B12 與兩種蛋白結合 ：

Haptocorrin（transcobalamin I）：攜帶約 70 到 80% 的血清 B12，但這部分是生物學上惰性的儲存形式，細胞無法從這裡取用 B12
Transcobalamin II（TC-II）：攜帶約 20 到 30%，但這才是唯一能把 B12 送進細胞的功能性運輸蛋白。細胞表面的 TC-II 受體（TCblR）識別 holotranscobalamin（holoTC），經受體媒介的胞吞將 B12 導入細胞。

這四棒的功能口訣是：保護者（haptocorrin），接著通行證（IF），接著收貨員（cubam 受體），接著宅配員（TC-II）。考題最愛的陷阱，是把「通行證」與「宅配員」混淆，或把「收貨員」與「通行證」的位置互換。

主軸二（本篇核心）：四個交接點各自失敗，治療方向完全不同。

這是整篇綜論最具臨床價值的段落。診斷邏輯的核心只有一句話：先定位斷點在哪一棒，再決定你的處置。

以下是以「斷點定位，接著疾病實體，接著為何這樣治療」為骨架的臨床演算法。

斷點一：IF 本身缺乏——沒有通行證。

典型病因：Pernicious anemia（PA，惡性貧血）：自體免疫性胃炎，抗壁細胞抗體（anti-parietal cell antibody）攻擊胃壁細胞，抗 IF 抗體（anti-intrinsic factor antibody）直接封鎖 IF，最終導致胃壁細胞不可逆損失，IF 分泌喪失。全胃切除（total gastrectomy）：手術切除全部胃壁細胞，IF 分泌完全中斷。先天性 IF 缺乏（congenital IF deficiency）：罕見的 GIF 基因突變，IF 蛋白結構異常或完全不分泌。

臨床後果：沒有通行證，B12 無法在迴腸被受體識別，主動吸收幾乎歸零 。

治療邏輯： 終身補充（high-dose oral 或肌肉注射 intramuscular，詳見主軸五）。

斷點二：胃酸不足——食物結合型 B12 釋放不出來（但 IF 健在）

典型病因：長期 PPI 使用：抑制胃酸分泌，食物蛋白質中的 B12 無法被胃酸與胃蛋白酶切離。萎縮性胃炎（atrophic gastritis）：胃腺體萎縮，壁細胞功能減退（但非自體免疫完全摧毀）。部分胃切除（partial gastrectomy）：保留部分壁細胞，IF 尚在。H. pylori 感染：慢性炎症影響胃酸與 IF 分泌。

這是一個最常被誤診的斷點。 關鍵邏輯：這些患者缺乏的是「釋放食物蛋白質結合型 B12 的能力」，但 IF 本身仍有分泌，游離的（free crystalline）B12 仍可正常結合 IF 並被吸收 。

因此：這些患者的 B12 缺乏被稱為 food-cobalamin malabsorption（食物結合型 B12 吸收不良），而非 pernicious anemia。治療上，口服結晶型 B12 補充劑（crystalline cyanocobalamin 或 hydroxocobalamin）即已足夠——不需要肌肉注射。吸收途徑完整，只需繞過「食物釋放步驟」
臨床重點： 長期 PPI 患者出現 B12 缺乏，直接換口服 crystalline B12 即可，不需要「升級」到肌肉注射，更不必貼上「惡性貧血」標籤。

斷點三：迴腸端的問題——受體不在了。

典型病因：Crohn's disease（克羅恩病）侵犯迴腸末端：肉芽腫性炎症破壞 cubam 受體所在的腸黏膜。迴腸切除（ileal resection）：手術切除迴腸末端，cubam 受體的解剖基礎消失。乳糜瀉（celiac disease）：嚴重的小腸絨毛萎縮，影響迴腸吸收面積。輻射性腸炎（radiation enteritis）：放射線傷害迴腸黏膜。

治療邏輯： 此時補充外源性 IF 完全無用——因為不是「通行證」的問題，而是「海關（受體）不在了」。必須依賴以下途徑 ：非腸道途徑（parenteral）：肌肉注射是標準選擇。高劑量口服利用被動擴散（passive diffusion）：詳見主軸五——雖然效率低，但在劑量足夠時仍可達標。

斷點四：半路被攔截——補 B12 是治標，治療才是解方。

典型病因：小腸細菌過度增生（SIBO，small intestinal bacterial overgrowth）：多重機制並存 ： 1. 厭氧菌直接消耗（consume）腸腔中的 cobalamin 2. 細菌產生的 cobalamin 類似物（analogues）競爭性結合 cubam 受體，阻斷真正 IF-B12 複合體的上岸 3. 嚴重時腸黏膜受損，直接損壞受體 4. 特別值得注意：SIBO 中細菌合成葉酸，可造成「血清葉酸偏高、血清 B12 偏低」的組合，有時掩蓋了診斷。魚絛蟲（Diphyllobothrium latum）：在小腸大量消耗 B12，特別是在迴腸近端即已將大部分 B12 攔截，IF-B12 複合體無法順利抵達末端迴腸。

治療邏輯： 單純補充 B12 無法根治，因為攔截者仍在。治療的關鍵是清除攔截者：SIBO，接著抗生素（如 rifaximin、metronidazole-based regimen）。Diphyllobothrium latum，接著驅蟲藥（praziquantel）

補充 B12 只是急性期的支持療法，病因未解決則會復發。

這個定位演算法從「出現 B12 缺乏」開始，依序往下問四組問題。

第一組問題問的是飲食與攝取。如果病人是素食者或惡性嗜酒者，那就不是吸收出了問題，補充即可，到這裡就結束。

如果不是，進入第二組問題，評估胃這一端。先問：有沒有長期使用 PPI、萎縮性胃炎，或部分胃切除？如果有，屬於食物結合型的吸收不良，口服結晶型 B12 就足夠。再問：有沒有抗 IF 抗體陽性、全胃切除，或胃壁細胞的自體免疫發炎？如果有，那是 PA 或 IF 缺乏，需要終身高劑量補充，口服或肌注皆可。

接著進入第三組問題，評估腸道。第一問：有沒有 SIBO 的跡象，例如腹脹、脂肪瀉，或葉酸上升而 B12 下降？如果有，治療以抗生素為主。第二問：有沒有寄生蟲的暴露史？如果有，就驅蟲。第三問：有沒有 Crohn's disease、迴腸切除，或放射腸炎？如果有，代表受體已經喪失，要走非腸道途徑補充。

最後是三個特殊情境。幼兒同時有巨球性貧血與蛋白尿，要懷疑 IGS，也就是主軸三談的那個。血清 B12 偏低但沒有症狀，要懷疑 haptocorrin 缺乏，是主軸四的內容。血清 B12 正常，新生兒卻有嚴重的巨球性貧血，要懷疑 TC-II 缺乏。

主軸三：一個受體壞掉，兩個器官同時發聲——Imerslund-Gräsbeck syndrome（IGS）

Imerslund-Gräsbeck syndrome（IGS） 是一個極具教學價值的罕見病，它示範了「一個分子在兩個器官各司其職」的系統生物學邏輯 。

Cubam 受體的雙重地址。

Cubam 受體（cubilin + amnionless）不只表現於迴腸末端的腸黏膜——它同樣表現於腎臟近曲小管（proximal convoluted tubule）的刷狀緣。在腎臟，cubam 的任務是回收腎小球濾過液中的低分子量蛋白質（如 retinol-binding protein、albumin 微量片段等）。

當 CUBN 或 AMN 基因突變時，兩個地址同時失守：迴腸端的 cubam 受體失去識別 IF-B12 的能力，B12 無法主動吸收，接著巨球性貧血（megaloblastic anemia）。腎臟近曲小管的 cubam 受體無法回收濾過的低分子量蛋白質，接著良性蛋白尿（benign proteinuria）

臨床表現：兒童期發病，呈現巨球性貧血 + 蛋白尿的組合。這個組合本身就是 IGS 的病理指紋。值得強調的是，IGS 的蛋白尿是良性的：它不會進展為腎衰竭，腎絲球功能保持正常，因為問題出在近曲小管的回收機制，而非濾過屏障 。
基因型-表現型細節：部分 CUBN 突變只影響腸道端的 B12 結合位點，不影響腎臟端的蛋白回收，因此這些患者有巨球性貧血但無蛋白尿。另一部分突變同時影響兩個部位，才出現完整的 IGS 表現 。

治療：補充外源性 IF 完全無效——通行證在，但海關（受體）壞了，補通行證毫無意義。必須以非腸道途徑補充 B12（肌肉注射 hydroxocobalamin），終身治療。蛋白尿本身不需要治療，監測腎功能即可。

一個病例系列顯示，接受 IM hydroxocobalamin 治療後（1000 µg/day），血紅素在三週內從 6.9 g/dL 回升至 11.4 g/dL，蛋白尿持續存在但腎功能完全正常 ——完美佐證了「治 B12 缺乏，不治蛋白尿」的處置邏輯。

主軸四：兩個「血清 B12 會騙人」的臨床實體。

案例一｜先天性 haptocorrin（TC-I）缺乏——假性低 B12。

Haptocorrin 缺乏的患者，血清 B12 濃度因為缺少主要的「儲存型」載體，測出來的數字極低，可能低至被判讀為嚴重缺乏的範圍 。但請記住：haptocorrin 攜帶的 B12 是生物學上惰性的，細胞並不使用這部分 B12。

這些患者終身無症狀，神經、造血、DNA 合成功能全部正常
不需治療
這是最常見的「假性 B12 缺乏（pseudodeficiency）」原因之一。

案例二｜Transcobalamin II（TC-II）缺乏——血清正常但細胞飢餓。

TC-II 缺乏幾乎完全相反 ：

血清 B12 完全正常——haptocorrin 仍然攜帶 80% 的 B12，讓血清數字看起來漂亮
但TC-II 是唯一將 B12 送進細胞的那一棒，TC-II 缺乏意味著細胞完全無法攝取 B12
嬰兒在出生後數週至數月內出現：

嚴重巨球性貧血（megaloblastic anemia）
免疫缺陷（agammaglobulinemia，中性球減少）
神經學症狀（肌張力異常、認知遲滯）
消化道症狀（腹瀉、生長停滯）
若未及時診斷，可致命或遺留不可逆神經損傷
治療：大劑量 IM hydroxocobalamin（至少每週 1 mg），以「灌飽」被動擴散進入細胞的那微小比例；多數中心以 IM 注射為標準，監測血 MMA 與 homocysteine 調整頻率。

這兩個案例指向同一個實驗室邏輯：

當臨床高度懷疑 B12 功能缺乏，但血清 B12 結果模稜兩可時，應改測 methylmalonic acid（MMA） 與 homocysteine——它們反映的是細胞內的功能性 B12 狀態，不受血清載體蛋白的干擾 。

血清 B12 低 + MMA 正常 + Hcy 正常，接著高度懷疑 haptocorrin 缺乏（假性缺乏）
血清 B12 正常 + MMA 升高 + Hcy 升高，接著高度懷疑 TC-II 缺乏或細胞內代謝異常。

臨床試驗與系統性回顧：

一項比較口服（1000 µg/day cyanocobalamin）與肌肉注射的前瞻性研究顯示，PA 患者接受口服補充 1 個月後，88.5% 已不再 B12 缺乏，血漿 B12 顯著上升，MMA 與 homocysteine 顯著下降，療效持續 12 個月 。

A study performed 45 years ago showed that 0.5 to 4% of radioactively labeled oral vitamin B12 can be absorbed by passive diffusion in both normal controls and patients with pernicious anemia. Thus, oral doses of 1000 μg deliver 5 to 40 μg, even if taken with food.

嚴重神經學表現（subacute combined degeneration）：需快速提升細胞內 B12 濃度，等不了被動擴散的效率

主軸六：Schilling test 的試劑消失了，但它的思考架構沒有。

Schilling test 的原始設計邏輯。

Schilling test（1954 年首創）的天才之處不在於它測的是什麼數字，而在於它逐段加條件以定位斷點的設計邏輯 ：

第一階段（Stage I）：單獨口服放射標記 B12，接著測 24 小時尿液排出率。若尿液排出低（吸收差），進入下一階段
第二階段（Stage II）：口服放射標記 B12 + 外源性 IF，接著若此時吸收恢復正常，接著斷點在 IF（PA）
第三階段（Stage III）：加入抗生素療程後再測，接著若吸收改善，接著斷點在 SIBO
第四階段（Stage IV）：加入胰酶後再測，接著若吸收改善，接著斷點在胰臟（胰臟外分泌不足）

這個「逐段排除、定位斷點」的邏輯，至今仍是臨床思考的骨架。

主軸七：114 年血液專科考題逐項評析。

題幹與選項
維生素 B12 吸收過程中，在胃中與之結合、並在迴腸被吸收的蛋白質是什麼？

內在因子（Intrinsic Factor）
球蛋白（Globin）
紅血球生成素（Erythropoietin）
運鐵蛋白（Transferrin）
鐵調素（Hepcidin）

逐項評析。

(A) 內在因子（Intrinsic Factor）——唯一正確答案，但題幹有一處值得點出的簡化。

就考試而言，(A) 毫無疑問是答案：IF 由胃壁細胞分泌，且它是唯一能讓 B12 通過迴腸末端 cubam 受體的通行證。

但題幹「在胃中與之結合」這句話在生理學上並不精確。在胃中率先與游離 B12 結合的其實是唾液來源的 haptocorrin——因為胃內的強酸環境會破壞 IF 對 B12 的結合力，卻正好是 haptocorrin 發揮保護作用的舞台。IF 雖然「在胃裡被分泌出來」，但它與 B12 的實際交棒發生在十二指腸：必須等胰臟蛋白酶分解掉 haptocorrin、且腸腔 pH 上升之後，B12 才轉手給 IF。

換句話說，正確的敘述應是：IF 由胃分泌，在十二指腸接手，在迴腸末端被吸收。這個細節在臨床上並非吹毛求疵——它正是「胰臟外分泌功能不足也會造成 B12 吸收不良」的機轉基礎（沒有胰酶，haptocorrin 不被分解，B12 就交不到 IF 手上），也是 Schilling test 第四階段要加胰酶的理由。

(B) 球蛋白（Globin）——錯誤。

Globin 是血紅素（hemoglobin）的蛋白質部分，與 heme 結合構成血紅素分子。它完全不參與 B12 的運輸或吸收，兩者唯一的交集只是「都與貧血有關」。

(C) 紅血球生成素（Erythropoietin, EPO）——錯誤。

EPO 是腎臟因應缺氧而分泌的荷爾蒙，作用於骨髓中的紅血球前驅細胞、促進其增殖與分化。它是「造血的指令」，而非「營養素的載體」。

(D) 運鐵蛋白（Transferrin）——錯誤，但這是設計最精巧的誘答。

Transferrin 確實是一個「在血中運送營養素的蛋白」——但它運送的是鐵，不是 B12。B12 在血中對應的運輸蛋白是 transcobalamin II。這兩者在功能上是平行的概念（都是血中的營養素載體），卻分屬兩套完全獨立的系統。

(E) 鐵調素（Hepcidin）——錯誤。

Hepcidin 是鐵代謝的主調節者，透過結合並內化 ferroportin 來關閉腸道鐵吸收與巨噬細胞鐵釋放。它與 B12 沒有任何關係。

四個誘答的共同結構——本題真正在考什麼。

值得注意的是，(B)(C)(D)(E) 全都屬於鐵與紅血球生成的系統：globin 是血紅素的蛋白部分，EPO 是造血荷爾蒙，transferrin 是鐵的運輸蛋白，hepcidin 是鐵的調節荷爾蒙。

出題者把兩套「都會造成貧血、但彼此完全無關」的系統並置在一起，真正考的是：你會不會因為「兩者都造成貧血」就把兩套機轉混為一談。 B12 的吸收運輸系統（haptocorrin，接著 IF，接著 cubam，接著 TC-II）與鐵的吸收運輸系統（DMT1，接著 ferroportin/hepcidin，接著 transferrin，接著 transferrin receptor）是兩條平行、獨立、互不交錯的道路，只是最終都匯流到同一個臨床表現——貧血。

真正的一字之差陷阱不在選項裡，而在概念裡。

本題五個選項的差異其實相當粗糙（一眼就能排除四個），真正容易出錯的地方藏在概念本身：
Haptocorrin 又稱 transcobalamin I，而真正把 B12 送進細胞的運輸蛋白是 transcobalamin II。

兩者只差一個羅馬數字，功能卻南轅北轍：Transcobalamin I（haptocorrin）：攜帶血中 70 到 80% 的 B12，但這部分生物學上惰性、細胞無法取用；它的缺乏造成「血清 B12 很低卻終身無症狀」。Transcobalamin II：只攜帶 20 到 30%，卻是唯一能把 B12 送進細胞的那一棒；它的缺乏造成「血清 B12 完全正常卻在數週內致命」

如果考題把選項改成「transcobalamin I 與 transcobalamin II 二選一」，難度會瞬間拉高數個等級——而這正是本題背後真正值得記住的東西。

收束：這一題真正要你記住的。

一個看似送分的選擇題，背後其實是一條有四個交接點的產線。而臨床上最有用的不是背下四個蛋白的名字，而是學會問「棒子掉在哪一棒」：

掉在胃酸這一棒（PPI、萎縮性胃炎），接著 IF 還在，接著口服結晶型 B12 就夠
掉在 IF 這一棒（惡性貧血、全胃切除），接著通行證沒了，接著終身補充，但高劑量口服已可取代肌注
掉在胰酶這一棒（胰臟外分泌不足），接著 haptocorrin 剪不開，接著補胰酶
掉在腸腔這一棒（SIBO、魚絛蟲），接著被半路攔截，接著抗生素或驅蟲，而不是補 B12
掉在 cubam 受體這一棒（Crohn's、迴腸切除、Imerslund-Gräsbeck），接著海關不在了，接著補 IF 完全無用，走非腸道途徑
掉在 TC-II 這一棒，接著血清 B12 會騙你，要看 MMA 與 homocysteine。

同樣是「B12 缺乏」四個字，六個斷點，六種完全不同的處置。
